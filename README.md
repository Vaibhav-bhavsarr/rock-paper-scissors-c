# Rock Paper Scissors in C

A simple, command-line Rock-Paper-Scissors game written in C. 

## About The Project
I created this project 3 years ago when I was first learning C programming. I am uploading it now to document my coding journey and preserve my early milestones! The game features a 3-round match against a randomized computer opponent and keeps track of the score.

## Features
* **Best of 3 Rounds:** Play three rounds to determine the ultimate winner.
* **Score Tracking:** Keeps track of both the player's and the computer's scores.
* **Randomized AI:** The computer opponent uses `srand()` and `time()` to generate random moves.
